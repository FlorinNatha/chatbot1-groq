# Nexus AI Chatbot

## About This Chatbot
Nexus AI is a highly responsive, conversational AI web application powered by the Groq API and built with Python and Streamlit. It leverages the highly capable `llama-3.3-70b-versatile` model to provide fast and intelligent responses.

### Key Features:
- **Lightning-Fast Generation:** Uses Groq's high-speed LPU inference engine for near-instant answers.
- **Modern Web Interface:** Built using Streamlit's intuitive chat UI components for a clean, user-friendly experience.
- **Conversation Memory:** Maintains the chat history throughout your session, allowing the AI to remember context and support natural, multi-turn conversations.
- **Streaming Responses:** Streams text token-by-token for a real-time, typewriter-like effect, minimizing wait times.
